# Android N14 壳源码

这是珠宝店主助手的 Android WebView 壳源码。它只负责把手机页面安全地打开到本机电脑助手，业务数据仍由电脑端服务保存。

## 当前能做什么

- Android 端打开 `http://127.0.0.1:17864/`；
- 只允许本机助手的页面和资源，拒绝跳到外部网页；
- 电脑服务未启动或 USB 映射未恢复时，显示“未连上电脑助手”；
- 不在 APK 里保存店铺密码、DeepSeek 密钥或真实商品照片。

## 当前边界

这份源码对应的是**电脑 + USB 连接试用版**，不是关电脑后通过公网直接使用的版本。要做无线独立版，还需要把本机地址改成 HTTPS 云端地址，并重新做服务鉴权、域名和服务器部署。

## 构建与连接

- `src/` 是安卓应用源码和资源，最低 Android 8.0（API 26），以 API 34 为构建目标。`tests/` 是本机地址限制的 Java 测试，可用 JDK 单独编译验证。
- `build_apk.py` 是原试用版的构建记录，依赖固定的内部目录、Windows 上本地配置的 JDK 和 Android SDK，以及本地试用签名。公开仓不附原签名，也没有提供下载即用的构建命令或 APK。
- 这个壳使用固定的本机地址，通过 USB 转接连到兼容的电脑端助手。仓库根目录的网页版试用（包括手机浏览器模式）不是随这个壳使用的专用电脑服务。
- 要让同事自行测试手机 App，还要交付可安装的 APK、配套服务和数据。不插电脑的版本还要完成 HTTPS 后端部署及真机验收。
