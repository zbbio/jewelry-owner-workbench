# Android N14 壳源码

这是珠宝店主助手的 Android WebView 壳源码。它只负责把手机页面安全地打开到本机电脑助手，业务数据仍由电脑端服务保存。

## 当前能做什么

- Android 端打开 `http://127.0.0.1:17864/`；
- 只允许本机助手的页面和资源，拒绝跳到外部网页；
- 电脑服务未启动或 USB 映射未恢复时，显示“未连上电脑助手”；
- 不在 APK 里保存店铺密码、DeepSeek 密钥或真实商品照片。

## 当前边界

这份源码对应的是**电脑 + USB 连接试用版**，不是关电脑后通过公网直接使用的版本。要做无线独立版，还需要把本机地址改成 HTTPS 云端地址，并重新做服务鉴权、域名和服务器部署。

## 构建

构建脚本使用 Windows 本机已有的 Android SDK/JDK，不下载依赖、不上传数据，也不把签名私钥放进仓库：

```powershell
python -B .\build_apk.py
python -B .\build_apk.py --verify-only
```

构建输出在本机的 `成品\jewelry-owner-n14.apk`（该目录不提交）。构建需要 Android SDK、JDK 和本机签名环境；没有这些工具时，可以先阅读和修改源码。

## 连接说明

电脑端先启动珠宝店主工作台服务，再通过 ADB/USB 将手机映射到电脑服务端口。源码不包含任何店铺数据；测试请使用你自己有权使用的照片和商品资料。
