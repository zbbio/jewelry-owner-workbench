# 有线安卓配套电脑服务

仅绑定本机回环地址，默认端口 17864。公开版使用程序内置的两张示例卡：A 有价，B 未填价。不读店铺数据库或真实商品。默认不调用付费模型。

在 Windows PowerShell 内，从本目录安装依赖、编译并启动：

~~~powershell
Set-Location agent
npm.cmd ci
npm.cmd run build
Set-Location ..
.\启动服务.ps1
~~~

先在电脑浏览器打开 127.0.0.1:17864。需要配对时，在自己的终端运行 `node .\配对管理.mjs issue`，不要转发一次性配对码。装好与此端口匹配的有线壳后，可在自己的设备上用 ADB 的 USB 反向连接同一个端口。用 `node .\配对管理.mjs stop` 停止后台服务。

源码包含已有的模型接入路径，默认暂停；这个示例不要求提供密钥，不附内部凭据注入文件。没有提供预签 APK 或预配对状态。
