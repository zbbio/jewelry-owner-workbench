# K2 差量：只合入干净的独立副本

此工具不安装、不发布，不操作仓内工作树或数据库。输入是已冻结的 P1 原 ZIP（SHA-256 `aa6cd0906cbc4a2660e4dd70be77589558c4e2d36247df9b0e18316b26199b14`）和 K1 接件 ZIP（`5a61e10bcc81243c863c0838db920f90f46c108ce861923c350290e656f65974`）。脚本在临时目录使用接件包里 K1 已核过的组装函数；重建 `n22-0c587b2d30ff040d4d8a1bc5` 后，所有 99 项须与 K1 一致才可继续。

从 `module` 目录运行，使用 Python 3.11+。若离开本项目，给每条命令加 `--base <P1原ZIP> --k1 <K1接件ZIP>`。不要在新目录预建任何文件。

~~~powershell
$copy = Join-Path $env:TEMP ("n99-k2-" + [guid]::NewGuid().ToString("N"))
python -B tools/integrate.py prepare  --host $copy
python -B tools/integrate.py apply    --host $copy
python -B tools/integrate.py check    --host $copy
python -B tools/integrate.py diff     --output (Join-Path $env:TEMP ("n99-k2-" + [guid]::NewGuid() + ".patch"))
python -B tools/integrate.py rollback --host $copy
python -B tools/verify_delta.py --evidence (Join-Path $env:TEMP ("n99-k2-" + [guid]::NewGuid() + ".json"))
~~~

五个调整文件：`n22-ui/index.html`（原“本店话题”按钮旁加独立按钮、独立非模态面板，不移动首页输入框）、`n22-ui/n22-app.js`（K1 已编译消息导航的同一私有作用域内接上 K2 IIFE）、`n22-ui/n22-app.css`（追加局部样式）、`NOTICE.md`（原声明不删除）、`release.json`（重新计算摘要与候选号）。不放开动态代码执行、网络地址配置或 WebView 权限；不替换 P/S 合同或新增可执行权限。

历史数据/审批票权威不在前端。若没有经原仓交付并且经评审的适配件，绑定保留为 `/*K2_BIND_READERS*/Object.freeze({})`。有真实上游时可在独立合件分支提供 `web/ports.js`（编译期 JavaScript 对象表达式代码，非用户输入或浏览器全局配置），复核其调用的是既有核权/版本接口，再重建、重签、独验。单测用替身留在测试路径，不要当正式读端口。

Python 方式按全树字节预检；额外文件、链接、硬链接、被手工编辑的原文件或已被改过的候选均报错退出，不覆写。提生成的 diff 给商品仓时也须在同一 K1 冻结版上做 `git -c core.autocrlf=false apply --check <patch>`，反向加 `-R`。文件回退不撤销其它仓已发生的业务事务。正式打包/部署仍由商品原仓负责。
