# 四仓与对话开发模块

| 路径 | 用途 |
| --- | --- |
| `workbench/相册仓` | 选图、来源、相似件分组和确认接口 |
| `workbench/商品仓` | 商品卡读取、资料校验、确认和写入 |
| `workbench/销售仓` | 问价、库存待办、销售引用与中文内容准备 |
| `workbench/内容仓` | 旧片、分镜、制作和采用业务源码 |
| `conversation` | 会话导航与原消息定位组件 |
| `integration` | 各仓分阶段交件，包括未合入的确认和模型入口等 |

这里是用于接入的源码。部分模块仍依赖内部宿主契约或经批准的运行资源；不应作为可直接安装或部署的整包。根目录的本地工作台仍是独立可运行的示例。各模块的版权和许可证以同目录中已有的声明为准。
