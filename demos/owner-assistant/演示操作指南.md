# 下载后自己演示：不需要开发者在旁边

## 先分清两个模式

|模式|需要什么|能看到什么|
|---|---|---|
|已有示例预览|首次准备环境时联网，不用模型密钥|130份合成示意图与卡片、示例店铺；不执行新的模型任务|
|真实模型演示|自己的DeepSeek密钥、网络、接口权限和可用额度|你发指令，模型选工具，实际重新分类/建卡、自动接待、列镜头|

相册、商品卡、销售接待、内容策划可独立使用。演示者不需要按相册→商品→销售→内容的固定顺序。下面逐个介绍是为了讲清楚按钮，并非业务前置链。

## 一、下载和第一次启动

1. 打开 [GitHub 仓库](https://github.com/zbbio/jewelry-owner-workbench)，点绿色 **Code → Download ZIP**，下载最新 main。
2. 在 **Windows 10/11、64位**电脑上，右键 **全部解压** 到可写文件夹，例如 `D:\珠宝演示`。不要在压缩软件里直接双击脚本，也不要只拿一个 CMD 文件。建议预留1GB空间。
3. 进入解压后的仓库最外层，双击 **一键启动四功能演示.cmd**。不要误点旧工作台、安卓USB或开发测试脚本。
4. 首次启动会显示下载/校验进度：自动准备专用 Node 23.11.1、Python 3.13.1、Pillow/openpyxl/et_xmlfile，并生成130张带“合成”标记的示意图、Excel价表和示例卡片。**无需预装 Node、Python、npm，无需云服务器或域名。** 网络慢时等待几分钟，不反复启动。
5. 浏览器自动打开 **珠宝店主助手 · 便携演示** 配置页。在密码框里填自己的 DeepSeek API 密钥，点 **保存并启动真实演示**。程序验证可调用性后打开助手。

密钥不会随GitHub下载提供；只在当前Windows用户的LocalAppData中DPAPI加密保存，不写到源码或浏览器页面。换电脑或换解压目录需重新配置。接口权限/额度不足按页面错误处理；配置页成功不等于视觉API权限或全部题目准确率已验。

如果暂时没有密钥，可点 **先看已有资料（不调用模型）**。此时点击新的整理/生成/问答请求会明确提示先配密钥，不拿固定回执代替真实模型执行。

## 二、四个功能分别怎么演示

### 1. 相册整理

在助手首页点 **相册整理**，或输入：

> 把今天这批珠宝照片按实物分组，先不要建卡

程序扫描本演示文件夹的数据，调用视觉API逐批处理。完成后出现 **查看分好的照片** 链接：点开，再点类别看图片。原图保持不变；异常批次会提示并把相关图片留在 **待确认**。等待完成前别重复点按钮，以免重复调用计费。

这里的130张图是程序绘制的圆形示意图，初始分类是夹具，**不代表真实珠宝识别准确率**。重新点击后走的是实际模型调用；本版本按外形品类分类，不承诺多角度同实物精确归并。

### 2. 商品卡

点 **商品卡**，或输入：

> 根据刚才的分类结果，自动为每件建立一个结构化商品卡 JSON 文件，字段包括颜色、品类、类型、材质、形态，先保存草稿

初始示例分类已备好，可以直接建卡，不必先重复整理。工具读取分类清单和合成价格Excel，用视觉API生成草稿。完成后点 **查看商品卡**，可看图片、价格、颜色、类型，再点单件详情；不需要自己读JSON。价格按Excel文件名匹配，尺寸/证书等缺资料时待核实。

一张图一张草稿，130张示例卡不是130件已验库存。初始卡片是夹具；点击生成之后才是本次真实模型结果。

### 3. 销售接待

1. 保留店主首页开着，点 **销售接待**，另开公开示例店铺。
2. 点手机店铺框内右侧的圆形 **客服**，以顾客身份输入 **这件多少钱？**，点击发送。
3. 默认示例货号 `DEMO105`，示例价 **260元**。顾客原聊天框自动收到回复；店主首页同步弹出店铺镜像和店主窗口，不需要店主审批或代发。
4. 再问 **这件有没有证书？**，没有依据时应提示核实，不编证书。
5. 想换另一件，可以把店铺地址末尾的 `sku=DEMO105` 换为 `sku=DEMO103`，该示例价 **240元**。两者都是合成价，不是真实店铺资料。

没有密钥或模型失败时，不会伪造“已自动回复成功”。店主主对话里输入 **客人问DEMO105这件有没有证书，帮我回一句，先别发**，走的则是内部草稿，不发到示例顾客。

### 4. 内容策划

点 **演示：内容策划**，或输入：

> 想看戴起来多大，给我列三个镜头，先别做片

返回三个拍摄镜头清单。**这版不生成、不剪辑、不发布视频**，不把文案当成片；GitHub公开包也不含商家原视频。

## 三、第二次启动、停止、恢复

- 以后仍双击仓库根目录 **一键启动四功能演示.cmd**。校验后复用已有环境、数据和同目录已加密保存的密钥，不重下全套环境，不重新生成示例数据。
- 保留启动窗口。结束时双击同一根目录 **停止四功能演示.cmd**，正常退出两个后台服务。
- 需要恢复初始示例：先停止，再进 `demos/owner-assistant`，双击 **恢复初始演示.cmd**。原生成结果先备份到 `data/backups`，原图和接待记录保留。恢复不调用模型。
- 自查环境：该目录的 **检查运行环境.cmd**；查看部署配置或换密钥可打开启动窗口打印的“启动管理页”。

## 四、地址、文件和常见问题

默认助手是 `http://127.0.0.1:4297/`；端口占用时自动换组，**以启动窗口打印地址为准**。这些都是当前电脑的本地地址，不是云端网址；在另一部手机输入同一个127.0.0.1不会访问到这台电脑。

- **下载失败**：一键准备依赖需访问 `nodejs.org`、`www.python.org`、`raw.githubusercontent.com`、`files.pythonhosted.org` 的HTTPS。检查网络后再次双击，已校验的下载复用；校验不符的文件不执行。
- **Windows提示下载文件或企业限制脚本**：先核对GitHub来源，企业受管电脑按管理员规则处理。启动器只在自己的文件夹准备运行时，不改全局PowerShell策略或系统Python/Node安装。
- **页面打不开**：先看启动窗口是否仍在、是否显示SETUP ERROR；不要只反复刷新旧地址。重新双击启动；若已运行，会打开现有管理页，不再起一套服务。
- **只能看图、问答不工作**：看看是不是选了只读预览。回管理页配置自己的密钥，再启动真实演示；同时确认余额和当前视觉接口权限。
- **第一次配好后关电脑**：这仍是本机演示，关电脑即停止；关电脑后手机独立使用需要另外部署云服务，本指南不冒充公网交付。
- **数据在哪**：都在本目录 `data`：`source`为合成图片，`price.xlsx`为合成价表，`demo`为分类/卡片输出，`runtime/messages.sqlite`为这台电脑新建的示例接待记录。已有数据不会因再次启动被自动覆盖。

当前一键入口只验Windows x64，不把同机隔离测试说成其他实体电脑、安卓或生产环境已验。代码、runtime-lock.json中的固定摘要和上游许可保留；更新依赖应另核版本及回归。
